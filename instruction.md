# Полная инструкция для студента: от установки до запуска чата (без примеров кода)

Эта инструкция поможет вам настроить среду разработки, создать проект чата с регистрацией и авторизацией (Flask + MySQL), а также освоить базовую работу с Git. Код вы будете писать самостоятельно, следуя указаниям преподавателя. Здесь приведены только действия и пояснения.

## 1. Установка необходимых программ

### 1.1. VS Code
- Скачайте установщик с официального сайта `code.visualstudio.com`.
- Запустите установку, при необходимости включите опцию «Add to PATH» (на Windows).
- После установки откройте редактор.

### 1.2. Git
- Скачайте Git с `git-scm.com`.
- При установке выберите пункт «Git from the command line and also from 3rd-party software».
- Проверьте установку: откройте терминал (командную строку) и выполните `git --version`. Должна показаться версия.

### 1.3. Python
- Скачайте Python версии 3.10 или новее с `python.org`.
- **Обязательно** отметьте галочку «Add Python to PATH» во время установки.
- Проверьте: в терминале `python --version` (или `python3 --version` на macOS/Linux).

## 2. Подготовка папки проекта и виртуальное окружение

1. Создайте на диске папку для проекта (например, `my_chat`).
2. Откройте эту папку в VS Code (File → Open Folder).
3. Откройте встроенный терминал (Terminal → New Terminal).
4. Создайте виртуальное окружение командой:  
   `python -m venv venv`
5. Активируйте окружение:
   - Windows: `venv\Scripts\activate`
   - macOS/Linux: `source venv/bin/activate`
6. Установите необходимые библиотеки:  
   `pip install flask mysql-connector-python`

## 3. Структура проекта и создание файлов

Внутри папки проекта создайте следующую структуру:
my_chat/  
├── app.py  
├── templates/  
│ ├── registration.html  
│ └── avtorization.html  
├── static/  
│ ├── css/  
│ │ └── style.css  
│ └── js/  
│ └── script.js  
└── .gitignore  

### 3.1. Создание файлов сервера (app.py)
- Создайте файл `app.py` в корневой папке.
- Напишите в нём код Flask-приложения, который:
  - Подключается к базе данных MySQL (используйте параметры, выданные преподавателем).
  - Обрабатывает маршруты:
    - `/` – отображает страницу регистрации.
    - `/login` – отображает страницу авторизации.
    - `/user_registration` (POST) – принимает JSON, добавляет пользователя в БД.
    - `/user_avtorization` (POST) – проверяет логин/пароль и возвращает результат.
    - `/chat` – принимает параметр `nickname` и выводит приветствие.
  - Использует `g` для хранения соединения с БД.
- Полный код даст преподаватель; вы можете скопировать его.

### 3.2. HTML-шаблоны
- В папке `templates` создайте файлы:
  - `registration.html` – форма регистрации (поля: имя, фамилия, логин, пароль).
  - `avtorization.html` – форма входа (поля: логин, пароль).
- Оба файла должны подключать CSS-файл (`../static/css/style.css`) и JS-файл (`../static/js/script.js`), а также библиотеку jQuery из CDN.

### 3.3. Файл стилей (style.css)
- Создайте в `static/css/style.css` CSS-правила для центровки карточки, стилизации полей и кнопки. Ориентируйтесь на пример преподавателя.

### 3.4. JavaScript-файл (script.js)
- В `static/js/script.js` напишите код на jQuery, который:
  - Перехватывает отправку форм (`submit`).
  - Отправляет асинхронные POST-запросы на соответствующие эндпоинты (JSON).
  - Обрабатывает ответы: при успешной регистрации перенаправляет на страницу входа, при успешной авторизации – на страницу чата.

### 3.5. Файл .gitignore
- Создайте в корне проекта файл `.gitignore` и добавьте в него строки:
venv/
pycache/
.env

## 4. Запуск приложения

1. Убедитесь, что виртуальное окружение активировано (в терминале видно `(venv)`).
2. Запустите сервер: `python app.py`
3. Откройте браузер и перейдите по адресу `http://127.0.0.1:5000`.
4. Зарегистрируйте нового пользователя, затем войдите с созданными данными.
5. После успешного входа вас должно перенаправить на `/chat`

## 5. Работа с Git

### 5.1. Инициализация и первый коммит
- Откройте терминал в папке проекта.
- выполните:
  - git config --global user.name "Your Name"
  - git config --global user.email "your.email@example.com"
- Выполните `git init` – создастся локальный репозиторий.
- Проверьте, что `.gitignore` лежит в корне и перечисляет ненужные файлы.
- Добавьте все файлы в индекс: `git add .`
- Сделайте коммит: `git commit -m "Initial commit: регистрация и авторизация"`

### 5.2. Подключение к удалённому репозиторию (GitHub)
- Создайте новый репозиторий на GitHub (без README и .gitignore).
- Скопируйте его URL (например, `https://github.com/ваш_логин/my_chat.git`).
- В терминале выполните:

```bash
git remote add origin https://github.com/ваш_логин/my_chat.git
git branch -M main
git push -u origin main
```bash

### 5.3. Разрешение конфликтов

Конфликт возникает, когда два разработчика меняют одни и те же строки файла.

**Как избежать:**
- Перед началом работы всегда выполняйте `git pull`.
- Коммитьте и пушите небольшие изменения.

**Если конфликт случился:**
1. Выполните `git pull` – Git покажет конфликтующие файлы.
2. Откройте эти файлы. Конфликтные участки помечены маркерами `<<<<<<<`, `=======`, `>>>>>>>`.
3. Отредактируйте файл вручную, удалив маркеры и оставив нужный код.
4. Сохраните файл и выполните:

```bash
git add .
git commit -m "Разрешил конфликт"
git push
```bash
