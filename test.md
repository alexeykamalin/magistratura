# Критерии получения зачёта по курсу

Для успешного завершения курса необходимо выполнить **все три** условия, описанные ниже.

---

## 1. Готовый MVP чата

Разработанное веб-приложение (чат) должно реализовывать следующий минимальный набор функций:

- [ ] **Регистрация пользователя** – создание учётной записи (имя, фамилия, логин, пароль). Данные сохраняются в базе данных MySQL.
- [ ] **Авторизация** – вход по логину и паролю.
- [ ] **Список пользователей** – после успешного входа отображается список зарегистрированных пользователей, с которыми можно начать чат.
- [ ] **Личный чат** – при выборе пользователя из списка открывается окно переписки:
  - Отправка текстовых сообщений.
  - Сохранение истории сообщений в базе данных.
  - Отображение истории переписки с выбранным собеседником.
- [ ] Интерфейс может быть простым, но все перечисленные функции должны работать без ошибок.

---

## 2. Git репозиторий

Репозиторий проекта на GitHub должен содержать:

- [ ] **Все файлы проекта** – исходный код, шаблоны, статические файлы (CSS, JS), файл `.gitignore`.
- [ ] **Product Backlog** – файл `BACKLOG.md` с перечнем пользовательских историй и приоритетами (MoSCoW).
- [ ] **README.md** – описание проекта, инструкция по запуску, краткая информация о технологиях.

**Требования к работе с Git:**
- Регулярные коммиты с осмысленными сообщениями.
- Ветка `main` (или `master`) должна содержать стабильную версию продукта на момент сдачи.

---

## 3. Выполнение заданий для обучающихся 10-х классов

Необходимо выполнить **не менее 50% заданий** из маршрута обучающегося 10-х классов.

- Ссылка на задания: [Google Sheets – Маршрут обучающегося](https://docs.google.com/spreadsheets/d/1LI4QX3UtlB021TBsD0eqRBIACjlHr_7OhXtLmfznLbY/edit?gid=0#gid=0)
- Задания проверяются преподавателем. Достаточно выполнить половину от общего числа.

---

**Итог:** Зачёт ставится при выполнении всех трёх пунктов. Каждый пункт обязателен.
